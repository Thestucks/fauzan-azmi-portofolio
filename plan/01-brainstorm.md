# 01 - Brainstorm

## Nama Project
Personal Portfolio - fauzan azmi alfiansyah

## Ringkasan Ide
Website portofolio pribadi untuk menampilkan profil, keahlian frontend, project pilihan, dan cara menghubungi saya secara profesional.

## Tujuan Utama
- Menampilkan identitas profesional sebagai Frontend / Full Stack Developer.[cite:16][cite:17]
- Menunjukkan skill utama, teknologi yang dikuasai, dan kualitas project.
- Menjadi media personal branding untuk recruiter, mentor, dan calon klien.
- Memudahkan pengunjung melihat project dan menghubungi saya.

## Target User
- Recruiter / HR tech
- Mentor / reviewer teknis
- Calon klien freelance
- Teman kolaborasi / tim project

## Masalah yang Ingin Diselesaikan
- CV biasa tidak cukup menunjukkan kualitas visual dan teknis project.
- Recruiter butuh cara cepat untuk melihat skill, stack, dan hasil kerja.
- Saya membutuhkan tempat terpusat untuk menampilkan project, GitHub, dan kontak.

## Scope MVP
- Hero section
- About me singkat
- Skills / tech stack
- Featured projects
- Contact section
- Link ke GitHub, LinkedIn, CV

## Di Luar Scope MVP
- Blog
- CMS admin
- Multi-language
- Dark mode dengan preferensi tersimpan
- Analytics lanjutan

## User Flow Utama
1. Pengunjung membuka website
2. Melihat headline singkat dan value proposition
3. Scroll ke featured projects
4. Melihat stack dan role saya
5. Membuka demo / GitHub project
6. Menghubungi saya lewat kontak

## Halaman / Section Utama
- Hero
- Projects
- Skills
- About
- Contact

## Referensi Visual
- Portfolio developer yang clean dan modern
- Gaya layout minimal, tidak terlalu ramai
- Fokus pada card project dan hierarchy konten

## Kata Sifat Visual
- clean
- modern
- professional
- minimal
- confident

## Preferensi Teknis
- Frontend: React + Vite
- Styling: Tailwind CSS
- Deployment: Vercel / GitHub Pages
- Data project: static JSON / local data

## Konten yang Harus Disiapkan
- Foto profil atau ilustrasi personal
- Deskripsi singkat diri
- 3–5 project terbaik
- Daftar tech stack
- Link GitHub
- Link LinkedIn
- CV

## Risiko Project
- Terlalu banyak section pembuka sebelum project tampil
- Deskripsi terlalu panjang
- Visual terlalu generik seperti template AI
- Project kurang menjelaskan peran dan hasil
