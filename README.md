# Fauzan Azmi Alfiansyah — Portfolio

> Modern personal portfolio website showcasing full-stack enterprise systems, IoT hardware implementations, interactive micro-apps, and UI/UX design prototypes.

🌐 **Live Website:** [thestucks.github.io/fauzan-azmi-portofolio](https://thestucks.github.io/fauzan-azmi-portofolio/)

---

## 🛠️ Tech Stack & Architecture

- **Core Framework:** [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Styling & Tokens:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Typography:** Bricolage Grotesque (Display) + Inter (Body)
- **Icons:** [Lucide React](https://lucide.dev/) + Brand SVGs
- **Deployment:** GitHub Pages

---

## 🚀 Featured Projects Included

1. **IHCS — Enterprise Employee Management System**
   - React, Spring Boot, MySQL, Geofencing Check-in, Payroll & Calendar Management
2. **Kujang Tracking System — Real-Time IoT GPS Tracker**
   - ESP32 / Arduino, GPS/GSM Module, Leaflet.js, PHP, MySQL, Telegram Bot Alert
3. **Setia Jaya Training Center — Learning & Certification Portal**
   - React, Vite, MySQL, Dynamic PDF Certificate Generation
4. **SIMAROON LABKOM — Academic Laboratory UI/UX**
   - Figma Design System, Interactive High-Fidelity Prototype
5. **Interactive Web Experiences (Birthday Series 1 — 5)**
   - Creative micro-apps featuring Canvas Confetti, Web Audio API, 3D CSS transforms, and gamified storytelling.

## 💻 Development & Build

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run linter
npm run lint

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
